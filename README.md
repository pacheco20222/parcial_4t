## Quick start

Requirements: Docker (Compose v2), bash, openssl, python3.

```sh
bash scripts/bootstrap.sh        # generate ./secrets (git-ignored): passwords, TLS CA/certs, JWT keys
docker compose up -d --build     # ~11 containers, all healthchecked
python3 scripts/smoke.py         # end-to-end check through the gateway
```

- Dashboard: https://localhost:8443 (citizen view at `/`, staff console at `/ops` after login). Gateway also serves `/api/telemetry/*`, `/api/ops/*`, `/hubs/live`, `/soc/` Grafana.
- Frontend dev: `cd frontend && npm ci && npx ng serve` → http://localhost:4200 (proxies to the gateway); see `frontend/README.md`.
- Logins: `admin|supervisor|operator@flood.local`, passwords in `secrets/seed_*_password`; Grafana `admin` / `secrets/grafana_admin_password`.
- Demo storm: `SCENARIO=storm INTERVAL_SECONDS=10 docker compose up -d simulator` (depth keeps rising past the 150 cm sensor range → readings flagged suspect → points end in Sin datos; for a full Normal→Alerta→Normal loop use `SCENARIO=cycle`).
- Site gate (public demo): `GATE_MODE=on docker compose up -d caddy` puts Caddy basic auth (user `GATE_USER`, default `demo`; password in `secrets/gate_password`, generated by `scripts/bootstrap.sh`) in front of the SPA, `/api/*`, `/hubs/*` and `/soc/*`. Off by default; `python3 scripts/smoke.py --gate` (or `GATE_MODE=on`) sends the credentials.
- SIEM demo (lab only): `docker compose --profile demo run --rm attack-sim` → alerts in Grafana → Alerting.

## Demo

`citizen-bot` starts by default and fills Reportes with synthetic Spanish reports
(no personal data). Disable with `CITIZEN_BOT_ENABLED=false`; minimum interval
`CITIZEN_BOT_MIN_INTERVAL_SECONDS=150` plus jitter keeps requests below 5/10 min/IP.

Run `bash scripts/demo-reset.sh` and type `RESET` (or pass `--yes`) to clear demo
alerts, work orders, citizen reports, processed events and outbox; restart folios
at 1, set point status to Normal, clear KPI caches, and restart both simulators.
Users, crews, audit history, readings, stream backlog and secrets are preserved.
The reset does not change `SCENARIO`; use the default `cycle` for a dry start.

Caddy returns 404 for missing static assets, caches existing hashed assets for a
year, and revalidates SPA HTML. Stale tabs recover failed lazy navigation with
one guarded reload per browser session.

## Layout

```text
services/telemetry-service/   FastAPI: MQTT ingestion, validation, Timescale, status machine, KPIs, Open-Meteo
services/ops-service/         ASP.NET Core: auth (JWT RS256 cookies, MFA), ERP/MES work orders, SignalR
simulator/                    Python sensor simulator + attack simulator
frontend/                     Angular 22 SPA (signals, SignalR, Leaflet), built into the caddy image
infra/                        postgres, mosquitto, redis, caddy, observability (loki/promtail/grafana)
scripts/                      bootstrap.sh (secrets), smoke.py (e2e)
.github/                      CI (tests, CodeQL, gitleaks, Trivy, compose smoke)
```
